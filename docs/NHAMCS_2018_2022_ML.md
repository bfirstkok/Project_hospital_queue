# NHAMCS 2018-2022 external-data experiment

This experiment uses the CDC/NCHS National Hospital Ambulatory Medical Care
Survey (NHAMCS) Emergency Department public-use files for 2018-2022.

## Why this source

The public-use files include initial vital signs and an ED triage/immediacy
field that align with several production-observable features in this project:

- age
- pain score
- respiratory rate
- heart rate
- systolic blood pressure
- diastolic blood pressure
- temperature
- pulse oximetry
- triage/immediacy level

The experiment intentionally does **not** manufacture project-specific fields
that NHAMCS does not directly supply. It also leaves `chief_complain` blank
instead of converting coded Reason-for-Visit values into fake free text.

## Label harmonization

For controlled external-data experiments only:

| NHAMCS IMMEDR | NHAMCS meaning | Project experimental label |
|---:|---|---|
| 1 | Immediate | RED |
| 2 | Emergent | PINK |
| 3 | Urgent | YELLOW |
| 4 | Semi-urgent | GREEN |
| 5 | Nonurgent | WHITE |

This is a label harmonization, not a claim that NHAMCS triage categories are
clinically identical to KTAS.

Values for blank, unknown, no-triage, or EDs without nursing triage are
excluded.

## Evaluation design

The benchmark is deliberately asymmetric:

1. Training candidate A: project data only
2. Training candidate B: project data + sampled NHAMCS rows
3. Validation for both candidates: **project-only held-out folds**

This answers the useful question: does public U.S. ED data improve performance
on the project's own target distribution?

The NHAMCS rows are sample-weighted below project rows by default and capped
per class. The workflow runs a sensitivity analysis at several weights.

## Reproduce locally

Download the CDC public-use Stata files for 2018-2022, extract them, then run:

```bash
python -m ai_triage.ml.import_nhamcs \
  --input 2018=/path/to/2018.dta \
  --input 2019=/path/to/2019.dta \
  --input 2020=/path/to/2020.dta \
  --input 2021=/path/to/2021.dta \
  --input 2022=/path/to/2022.dta \
  --output /tmp/nhamcs_runtime.csv
```

Then:

```bash
python -m ai_triage.ml.benchmark_nhamcs_augmentation \
  --nhamcs-csv /tmp/nhamcs_runtime.csv \
  --max-external-per-class 2000 \
  --weights 0.10,0.25,0.35,0.50,1.00 \
  --output-dir ai_triage/reports/nhamcs_benchmark
```

The GitHub Actions workflow performs the public CDC download, conversion, and
benchmark automatically and uploads only aggregate reports.

## Production rule

Do not replace the production model based only on an improvement in one
metric. High-acuity recall, route accuracy, severe under-triage, and stability
on project-only validation should be reviewed together.
